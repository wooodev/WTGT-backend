# 🌟 catsgotogedog
## 📚 프로젝트 개요
> 반려동물과 함께 생활하는 사람들을 대상으로, 반려동불 동반 가능한 여행지에 대한 정보를 제공하는 서비스

---
## ⚙️ 기술스택
Java, Springboot, Mysql, JPA, Elastic search, Docker, NCP Cloud, Clova AI, Flyway

## ⛏️ 주요 기능

장소 정보 제공 : 반려동물과 동반 가능한 장소 정보 제공

해당 장소 내 위치, 이용안내, 유의사항 등 필수 정보 제공

문화시설, 관광지, 행사, 숙박, 음식점, 쇼핑, 레포츠 등 7가지 카테고리로 나누어 검색 가능

리뷰 기능 : 해당 장소에 방문한 유저의 리뷰를 통한 정보 공유

AI 플래너 : 유저의 상황에 맞게 AI가 장소를 추천해주는 기능
